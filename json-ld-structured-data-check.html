JSON-LD 구조화 데이터 검사 방법

JSON-LD는 검색엔진과 AI 시스템이 페이지의 대상과 관계를 구조적으로 이해하도록 돕는 형식입니다. 문법만 맞는다고 충분한 것이 아니라 실제 페이지 내용과 일치해야 합니다.

  1. JSON 문법 오류가 없는지
  2. @type이 페이지 목적과 맞는지
  3. name, url, sameAs 등 핵심 속성이 일관적인지
  4. 보이지 않는 내용을 구조화 데이터에만 넣지 않았는지
  5. Organization·Product·Article 등 엔티티가 중복/충돌하지 않는지
  6. canonical URL과 구조화 데이터의 URL이 일치하는지

문법보다 중요한 일치성

구조화 데이터가 유효하더라도 실제 페이지에 없는 가격, 평점, 작성자 정보를 넣으면 신뢰 가능한 신호가 되기 어렵습니다. 보이는 콘텐츠와 구조화 데이터가 같은 사실을 말해야 합니다.

엔티티 일관성

브랜드명, 조직명, 제품명, 공식 URL을 페이지와 구조화 데이터에서 같은 형태로 유지하면 검색 시스템이 동일한 대상을 이해하는 데 도움이 됩니다.
