한 리포트에서 확인하세요.

공개 웹사이트 URL을 입력하면 Google·Naver·AI 검색 노출과 관련된 기술 신호를 자동 점검하고, 우선순위와 수정 방향이 포함된 HTML 리포트를 생성하는 Windows용 감사 툴킷입니다.

다운로드형 디지털 제품 · 월 구독료 없음
구매 후 Windows PC에서 반복 실행할 수 있도록 설계되었습니다.

사용은 3단계입니다

1. 실행
ZIP 압축 해제 후 Windows EXE를 실행합니다.
2. URL 입력
검사할 공개 웹사이트 주소를 입력합니다.
3. 리포트 확인
우선순위와 수정 방향이 담긴 FULL HTML 리포트를 확인합니다.

주요 기능

  • Google 검색 기본 기술 요소 점검
  • Naver Yeti 접근성 및 관련 기술 신호 점검
  • AEO · GEO · LLMO · NEO 관련 체크
  • P0 긴급 / P1 중요 / REVIEW / OK 우선순위
  • 확인 근거, 영향도, 난이도, 권장 수정방법
  • 시간예산 도달 시 부분 검사 여부 명확히 표시

어떤 버전을 선택하면 되나요?

Basic이 맞는 경우
  • 내 사이트 한 곳의 기술 문제를 빠르게 점검하고 싶음
  • 경쟁사 비교나 과거 대비 변화 추적은 필요 없음
  • 우선순위와 권장 조치가 포함된 HTML 리포트가 필요함
PRO가 맞는 경우
  • 경쟁사 최대 3개와 같은 기준으로 비교하고 싶음
  • 어디서 밀리고 있는지 우선순위를 보고 싶음
  • 수정 전후 개선·악화를 반복 확인하고 싶음

필요 환경

Windows PC · 인터넷 연결 · 공개적으로 접속 가능한 웹사이트 URL

독립 실행형 Windows EXE가 포함되어 있어 별도의 Python 설치가 필요하지 않습니다.

구매 전에 꼭 확인하세요

  • 월 구독이 아닙니다. Basic과 PRO 모두 1회 결제형으로 준비 중입니다.
  • 공개 URL 전용입니다. 관리자 계정·비밀번호를 요구하지 않습니다.

  • 검색 성과 보장 상품이 아닙니다. 기술 감사와 우선순위 정리를 돕는 도구입니다.
  • 부분 감사가 발생할 수 있습니다. 사이트 차단·응답 지연이 있으면 결과에 표시합니다.

자주 묻는 질문

이 도구가 검색 순위 상승을 보장하나요?

아닙니다. 공개 웹사이트의 기술 신호를 점검하고 수정 우선순위를 정리하는 감사 도구이며 순위, 트래픽, 색인 또는 AI 인용을 보장하지 않습니다.

Python을 설치해야 하나요?

아닙니다. Windows 독립 실행형 EXE가 포함되어 있어 별도 Python 설치 없이 사용할 수 있습니다.

어떤 사이트를 검사할 수 있나요?

인터넷에서 공개적으로 접속 가능한 웹사이트 URL을 검사할 수 있습니다. 관리자 계정이나 비밀번호는 필요하지 않습니다.

Basic을 샀다가 PRO가 필요해지면 어떻게 하나요?

현재는 두 버전을 별도 상품으로 준비 중입니다. 실제 스토어 활성화 후 업그레이드 정책과 구매 경로를 이 페이지에 명확히 안내하겠습니다.

사이트 로그인 정보가 필요한가요?

아닙니다. 공개적으로 접속 가능한 URL을 대상으로 동작하도록 설계되었습니다. 관리자 계정이나 비밀번호를 입력하지 마세요.

경쟁사 비교는 검색 순위 예측인가요?

아닙니다. PRO는 동일한 기술 감사 기준으로 사이트 상태 차이를 비교하는 기능이며, 검색 순위나 향후 트래픽을 예측하지 않습니다.
