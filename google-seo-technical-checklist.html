구글 기술 SEO 체크리스트

구글 SEO의 기술 점검은 “검색 로봇이 접근할 수 있는가 → 색인 가능한가 → 대표 URL이 명확한가 → 페이지 내용을 이해할 수 있는가” 순서로 보는 것이 효율적입니다.

  1. HTTP 200 응답과 리디렉션 체인
  2. meta robots / X-Robots-Tag
  3. 고유한 title과 meta description
  4. canonical 일관성
  5. sitemap 포함 여부
  6. H1 및 본문 렌더링
  7. JSON-LD 구조화 데이터 유효성
  8. 내부 링크와 깨진 링크
  9. 이미지 alt와 성능 기초 요소

Google 기술 점검 순서

  1. 크롤링 접근: robots.txt와 응답 상태를 확인합니다.
  2. 색인 지시: noindex가 의도치 않게 적용되지 않았는지 확인합니다.
  3. 대표 URL: canonical이 올바른 페이지를 가리키는지 확인합니다.
  4. 발견성: sitemap과 내부 링크에서 중요한 URL이 발견되는지 확인합니다.
  5. 페이지 신호: title·description·H1·구조화 데이터 등 공개 기술신호를 점검합니다.
  6. 수정 후 재검사: 동일 URL을 다시 검사해 기술 문제가 해소됐는지 확인합니다.

이 체크리스트는 공개 기술신호를 진단하는 절차입니다. 실제 Google 색인 상태·검색어 노출·클릭 데이터는 Search Console 등 검색엔진 측 데이터와 함께 확인해야 합니다.

색인 가능성부터 확인

페이지가 정상 응답하더라도 noindex가 걸려 있거나 canonical이 엉뚱한 URL을 가리키면 검색 노출에 문제가 생길 수 있습니다.

중복 신호를 줄이기

제목과 설명이 여러 페이지에서 반복되면 각 페이지의 역할이 불명확해질 수 있습니다. 페이지별 고유한 주제와 메타 정보를 유지합니다.

구조화 데이터

JSON-LD는 페이지의 의미를 구조적으로 전달하는 수단입니다. 문법 오류뿐 아니라 실제 페이지 내용과 일치하는지 확인해야 합니다.

내부 링크와 발견성

중요 페이지가 사이트 내부에서 충분히 연결되어 있는지, 깨진 링크가 없는지, sitemap과 실제 링크 구조가 충돌하지 않는지 점검합니다.
