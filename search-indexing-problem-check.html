검색 색인 문제 진단 방법

페이지가 검색에 보이지 않는다고 바로 콘텐츠 문제라고 판단하면 진단 순서가 꼬일 수 있습니다. 먼저 기술적으로 접근 가능하고 색인 가능한 상태인지부터 확인해야 합니다.

  1. URL이 200 응답인지
  2. 리디렉션이 의도한 최종 URL로 가는지
  3. meta robots·X-Robots-Tag에 noindex가 없는지
  4. robots.txt가 크롤링을 막지 않는지
  5. canonical이 다른 URL을 대표본으로 지정하지 않는지
  6. sitemap에 대표 URL이 포함되어 있는지
  7. 중요 페이지로 가는 내부 링크가 존재하는지

색인과 순위는 별개입니다

색인이 가능하다는 것은 검색 결과에 반드시 높은 순위로 노출된다는 뜻이 아닙니다. 색인 문제를 해결한 뒤에도 콘텐츠 품질, 경쟁도, 사이트 신뢰도 등 별도 요소가 영향을 줍니다.

부분 감사에 주의

사이트가 느리거나 크롤링을 제한하면 자동 감사가 일부만 완료될 수 있습니다. 이 경우 결과를 전체 사이트 상태로 과대해석하지 않아야 합니다.

자동 점검으로 먼저 줄일 수 있는 범위

HTTP 상태, noindex, robots, canonical, sitemap 같은 기계적으로 확인 가능한 항목은 먼저 자동 점검하고, 그 다음 콘텐츠 품질이나 검색 경쟁도처럼 사람이 판단해야 하는 영역으로 넘어가면 진단 시간을 줄일 수 있습니다.
