SEO 감사 체크리스트

사이트 SEO 감사는 점수 하나를 보는 것보다 크롤링 가능성 → 색인 지시 → 대표 URL → 페이지 신호 → 내부 발견성 순서로 확인하는 편이 문제 원인을 찾기 쉽습니다.

점검 순서
  1. HTTP 응답과 리디렉션 확인
  2. robots.txt 크롤링 정책 확인
  3. noindex와 X-Robots-Tag 확인
  4. canonical 대표 URL 확인
  5. sitemap과 내부 링크 확인
  6. title·description·H1 중복 확인
  7. JSON-LD와 공개 콘텐츠 일치 확인

자동 점검과 사람 검토를 구분하세요

HTTP 상태, robots, noindex, canonical 같은 공개 기술 신호는 자동 확인에 적합하지만 콘텐츠 품질이나 실제 검색 경쟁력은 별도 검토가 필요합니다. 자동 결과만으로 검색 성과를 보장할 수는 없습니다.

수정 후 다시 확인하세요

문제를 수정한 뒤 같은 URL을 다시 점검해 기술 신호가 실제로 바뀌었는지 확인합니다. 검색엔진의 실제 색인·노출 데이터는 Search Console이나 해당 검색엔진 도구에서 별도로 확인해야 합니다.
