noindex 확인 방법

페이지가 정상 접속되는데 검색에 나오지 않는다면 noindex가 의도치 않게 설정됐는지 확인할 필요가 있습니다. HTML 메타 태그뿐 아니라 HTTP 헤더의 X-Robots-Tag도 확인해야 합니다.

  1. HTML의 meta robots 확인
  2. HTTP 응답 헤더의 X-Robots-Tag 확인
  3. CMS·플러그인의 사이트 전체 비공개 설정 확인
  4. sitemap에 noindex URL이 섞여 있는지 확인
  5. canonical이 다른 URL을 가리키는지도 함께 확인

robots.txt와 혼동하지 마세요

robots.txt로 크롤링을 막는 것과 noindex로 색인을 막는 것은 목적이 다릅니다. 두 설정을 동시에 무작정 쓰기보다 원하는 동작을 먼저 정의해야 합니다.

배포·스테이징 사고

개발 중 사용하던 noindex가 운영 배포 후 남아 있는 경우가 있습니다. 출시 직후에는 메타와 헤더를 실제 운영 URL에서 재검사하는 것이 안전합니다.
