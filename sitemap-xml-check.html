sitemap.xml 검사 방법

sitemap은 검색엔진이 발견해야 할 대표 URL을 정리하는 파일입니다. 존재 자체보다 실제 색인 대상 URL과 일치하는지가 중요합니다.

  1. 정상 공개 URL만 포함
  2. 404·리디렉션 URL 제외
  3. noindex 페이지 제외
  4. canonical 대표 URL과 일치
  5. HTTP/HTTPS·www/non-www 혼용 여부 확인
  6. 대규모 사이트는 파일 크기와 샤딩 구조 확인

가장 흔한 문제

이전 URL이 sitemap에 남아 있거나, canonical은 A를 가리키는데 sitemap은 B를 제출하는 식의 신호 충돌입니다.

변경 후 확인

sitemap을 수정했다고 바로 색인이 보장되는 것은 아닙니다. 검색엔진 도구에서 제출 상태와 실제 색인 결과를 따로 확인해야 합니다.
