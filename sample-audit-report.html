P1 · canonical

대표 URL 신호 불일치

확인 근거: 페이지 canonical이 현재 URL과 다른 경로를 가리키는 예시.

영향: 대표 URL 신호가 sitemap·내부 링크와 충돌하면 검색엔진이 어떤 URL을 대표본으로 볼지 혼란이 생길 수 있습니다.

권장 조치: canonical, sitemap, 리디렉션, 내부 링크가 같은 대표 URL을 가리키도록 확인합니다.

P1 · robots

Naver Yeti 접근 정책 확인

확인 근거: Yeti 전용 규칙 또는 전체 크롤러 규칙에서 접근 제한이 감지된 예시.

권장 조치: 의도한 차단인지 검토하고 공개 검색 대상 페이지의 크롤링을 막고 있다면 정책을 수정합니다.

REVIEW · AEO/GEO

답변형 콘텐츠 품질 사람 검토

확인 근거: 자동 검사로 존재 여부는 확인할 수 있지만 사실성·명확성·출처 품질은 기계적으로 확정하기 어려운 항목입니다.

권장 조치: 질문에 대한 직접 답변, 날짜·수치·근거, 출처, 독립적으로 이해 가능한 문단 구조를 사람이 확인합니다.

이 결과 형식이 필요한 경우
